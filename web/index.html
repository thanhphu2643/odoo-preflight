Check a whole repository

        
Install the command and point it at your addons.

        
pipx install git+https://github.com/thanhphu2643/odoo-upgrade-check

        
odoo-upgrade-check path/to/addons --to 17

      

      

        
On every pull request

        
With --format github, findings appear on the changed lines in GitHub Actions. It also runs as a pre-commit hook.

      

      

        
Checked against Odoo itself

        
Every rule was checked in the source of the Odoo version it names, and the lists of removed models, fields, views and JS modules are extracted from the official Odoo 16, 17 and 18 images.
